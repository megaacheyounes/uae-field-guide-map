# UAE Field Guide offline map

[Download the UAE map and place directory (50 MB)](https://github.com/megaacheyounes/uae-field-guide-map/releases/download/2026-11-18-directory/UAE-map.zip). UAE Field Guide 1.7 for Android includes this pack in the installer. You can also download it from Map options or transfer the ZIP and select **Replace map pack**.

The pack includes a Mapsforge map and a searchable SQLite directory with 48,140 entries across all seven emirates, including Hatta and Khor Fakkan. Its 17 service categories cover food, water, transport, supplies, health and everyday services. Water points tagged for drinking are listed separately from wells, springs and taps of unknown quality. Current supply and access need checking locally.

The map and directory come from the same OpenStreetMap France UAE extract dated 17 November 2026. The ZIP includes the manifest and the individual file checksums. SHA-256 of the ZIP is `ef43fd4b9f908f0c98d4c47703868a80e85bce5f0313a040b5537e5300447c38`.
