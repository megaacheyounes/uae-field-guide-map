# UAE Field Guide offline map

[Download the UAE map pack (46 MB)](https://github.com/megaacheyounes/uae-field-guide-map/releases/download/2026-11-17/UAE-map.zip). UAE Field Guide for Android can download this pack from its Map screen or import the ZIP from Files.

The pack includes a Mapsforge map and a searchable SQLite place index for all seven emirates, including Hatta and Khor Fakkan. Both were built from the same OpenStreetMap France UAE extract, dated 17 November 2026. The ZIP includes the pack manifest and individual file checksums.

SHA-256 of the ZIP is `93486a38b2572eafc8d0563d9632ee1226de7b02c6b3a21a58ac295a89d3c6a3`.
